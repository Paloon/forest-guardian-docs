🎮 หน้าเกม Forest Guardian

ส่วนประกอบ UI ฉบับ Prototype ปัจจุบัน → อนาคต

📸 ภาพปัจจุบัน — หน้าเกมเปล่าๆ ยังไม่มี E-waste, ระบบต่างๆ
🔍 ส่วนประกอบปัจจุบัน
1
🌍 3D Scene / Terrain
✅ พื้นตาราง + ฟ้า + Cube prototype
จะเปลี่ยนเป็นป่า 5 โซน (ป่าสน, ที่โล่ง, ริมน้ำ, เนินเขา, ถ้ำ) พร้อมต้นไม้ หิน ดอกไม้ Low-poly
2
🎯 Crosshair (จุดเล็ง)
✅ จุดขาวกลางจอ — ใช้สแกนหา E-waste
เมื่อสแกนเจอ → เปลี่ยนสี + ไฮไลท์ตัว E-waste, มีเสียง Ping
3
📦 Hotbar 6 ช่อง (กด 1-6)
✅ 6 slots ว่าง — กรอบเขียว, เลข 1-6
เมื่อเก็บ E-waste → ของจะมาโผล่ในช่อง, กดเลขเพื่อเปลี่ยนของที่ถือ, มี icon + ชื่อ
📸 E-Waste Information Popup — กด F สแกนเจอขยะ
📖 Knowledge Popup (กด F สแกน)
1
📷 รูป E-waste
✅ กล่องดำ placeholder
จะเปลี่ยนเป็นรูป/icon ของ E-waste แต่ละชนิด
2
⚠️ ระดับอันตราย
✅ ตัวเลข 4/5 + สีตามระดับ
เพิ่มสัญลักษณ์ + สีพื้นหลังเปลี่ยนตามระดับ
3
📄 ข้อมูล E-waste
✅ ชื่อ + รายละเอียด + สารพิษ
ข้อความสั้นลง, อ่านง่ายขึ้น, ใช้ bullet points แทนความเรียง
4
♻️ วิธีกําจัดที่ถูก
✅ "นำส่งร้านรับซื้อของเก่า"
เพิ่ม icon + สีเขียวแยกชัด
5
❌ วิธีกําจัดที่ผิด
✅ "ทิ้งรวมกับขยะทั่วไป"
เพิ่ม icon + สีแดงแยกชัด

✏️ ปรับปรุง: ข้อความเยอะเกินไป

ตอนนี้ใน Popup มีข้อความบรรยายยาว — ควรตัดให้สั้นลง, ใช้ bullet points, หรือแบ่งเป็น tabs

ตัวอย่างข้อความที่กระชับขึ้น:

  • ชื่อ: ไมโครเวฟ | อันตราย: ⚠️ 4/5
  • สารพิษ: ตัวเก็บประจุ (คายประจุได้), แมกนีตรอน
  • ✅ กำจัดถูก: ส่งร้านรับซื้อของเก่า
  • ❌ กำจัดผิด: ทิ้งรวมขยะทั่วไป, ทิ้งน้ำ

➕ เร็วๆ นี้ — UI ที่จะเพิ่ม

❤️
HP Bar
แถบแดงมุมบนซ้าย — ลดเมื่ออยู่ในหมอก/ทิ้งผิด
💰
Wallet
ตัวเลขเงิน — ได้เมื่อขาย E-waste ถูกวิธี
🌫️
Pollution Bar
100% → 0% — ยิ่งเก็บขยะเยอะ ยิ่งลด
📊
Progress Counter
"เก็บไปแล้ว 3 / 15 ชิ้น" — บอกความคืบหน้า
📖
Knowledge Popup
ข้อมูล E-waste: สารพิษ, วิธีกําจัด, ระยะย่อยสลาย
🏪
Shop UI (กด B)
ซื้อหน้ากากกันพิษ, ยา HP, ไฟฉาย, ชุดป้องกัน
♻️
Disposal Points
6 จุดใน map — รับ E-waste ตามประเภท WEEE
🏁
Game Over / Clear
HP=0 → Game Over, เก็บครบ → Clear!
